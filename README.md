# insigoo SIA · 互联网公益项目逻辑体检信度检验

本仓库是研究报告《公益项目"逻辑体检"的一次信度检验——200 个公开募捐项目的批量快检与全量双人重判》（2026-11）的配套数据包。它回答的问题不是"哪些项目好"，而是**"这套体检工具本身稳不稳"**。

> **重要边界**：本报告为方法学信度记录，`publishable=false`。双人逐符号一致率 84.15%（1683/2000）判定 REVIEW，未达 90% PASS 门槛。全部分数只用于方法学讨论，**不构成对项目成效的评价，不得用于排序，不得按"已达标"引用**。

## 计分口径

统一加权制：✅=1 分，⚠️=0.5 分，❌=0 分，满分 10 分。
分档：≥6 分 = 优先推进；3–5.5 分 = 补充复评；<3 分 = 暂不推荐。
判据：insigoo SIA v3.3.0 · L1 快速自检判据 v1.2 收紧版（"证据三段归位"）。

## 信度检验方法

- **全量双人独立重判**：200 份 × 10 项 = 2000 个符号位，两名互相隔离的复核员按同一版判据各自盲判，不读原分数、不读对方结果。
- **第三方仲裁**：317 处分歧由第三方逐条回读公开证据裁定（取甲 161 / 取乙 150 / 独立第三值 6）。
- **结论**：一致率 84.15%，低于 20 份小样本阶段的 89.0%，证明小样本高估了判分员间信度。

## 数据脱敏政策

- 公开数据包**只含聚合统计**（总分、分档、逐题计数、分层、领域、缺口率、信度），**不含任何单个项目的名称、编号、页面、证据笔记**。
- 报告全文同样零项目实名、零项目编号。
- 评估仅基于项目公开页面信息，仅反映逻辑自洽维度的披露质量，不构成对项目执行效果、资金使用效率或机构整体能力的评价；**未披露不等于未实施**。

## 与百项快检的关系

本仓库是 SIA 框架的**第二份批量实测**，与首份《互联网公益项目逻辑自洽性百项快检观察》（100 项目，均分 4.97）是两件独立的事：样本来源、抽样方式均不同（本轮为"在募且披露足够做体检"合格池内分层随机），**不并列总分、不做高低比较**。框架标准见 [insigoo-sia-open](https://github.com/insigoo/insigoo-sia-open)，首份观察见 [sia-100-report](https://github.com/insigoo/sia-100-report)。
